# hxyfront-62014 赛鸽训放记录

源提示词编号：9

我想做一个面向赛鸽棚的训放记录前端工具，鸽主可以记录足环号、血统、训放地点、放飞距离、天气、归巢时间、飞行速度、健康状态和配对记录。页面需要有鸽棚总览、训放成绩排行、未归巢提醒、单羽赛鸽档案和按血统筛选的历史成绩。

## 回棚检疫准入

- **入棚登记**：每羽归棚须登记体温、呼吸道、粪便、运输笼四项，缺项不保存。
- **异常转隔离**：任一异常项（体温超出 40.0–42.5℃、呼吸道异常、粪便异常）只能转隔离，无其他选项。
- **隔离与观察**：隔离鸽退出归巢率与成绩排行；同运输笼鸽转入观察，保留原成绩记录并继续参与统计。
- **恢复条件**：隔离满 48 小时且复检正常才可解除；未恢复前再次训放会被拦截并说明原因。
- **更正检疫**：更正产生新版本记录，排行、提醒、单羽档案同步重算；旧结论保留可查。

## 分层结构

```
src/
  domain/
    types.ts   领域类型（鸽、训放、检疫记录、解除事件）
    rules.ts   状态规则（纯函数）：校验、状态推导、48h+复检恢复、
               训放准入拦截、排行/归巢率/提醒/档案推导
  data/
    store.ts   持久化：localStorage 读写与种子数据
    useLoft.ts React 粘合层：状态变更一律"规则校验 → 新 state → 落盘"
  components/  界面组件（只负责展示与收集，不含规则）
```

所有界面结论都由 `LoftState` 经规则层推导，数据保存在浏览器本地，刷新后保持一致。
