# hxyfront-62014 赛鸽训放记录 · 回棚检疫准入

面向赛鸽棚的训放记录前端工具：鸽主可以记录足环号、血统、训放地点、放飞距离、天气、归巢时间、飞行速度、健康状态与配对记录；
并在回棚环节执行检疫准入，自动推导隔离/观察状态，联动归巢率、成绩排行、提醒和单羽档案。

## 回棚检疫规则

1. **缺项不保存**：每羽归棚必须登记体温、呼吸道、粪便、运输笼四项及检疫时间，任一缺失或无效直接拒绝保存。
2. **异常只能转隔离**：体温超出赛鸽正常区间 40.0~42.5℃，或呼吸道/粪便/运输笼任一异常，该羽立即进入隔离。
3. **同笼鸽观察**：与异常鸽在同一次训放同一运输笼的其他鸽只进入观察，**原有训放与成绩记录全部保留**，不强制退出训放（给提示）。
4. **隔离恢复**：隔离满 48 小时 **且** 之后完成四项正常的复检才恢复；期间（即使复检已正常）再次训放一律拦截并说明剩余时间；
   复检异常则从复检时刻重新计时 48 小时。
5. **隔离鸽退出统计**：隔离期间退出归巢率与成绩排行；观察鸽保留原记录；恢复后自动重新参与。
6. **更正留痕**：检疫记录可更正（必须填更正原因），每次更正保留旧结论快照；排行、提醒和单羽档案依据当前结论同步重算，旧结论可查。

## 分层结构（状态规则 / 持久化 / 界面分离）

- `src/domain/types.ts` — 领域数据模型
- `src/domain/rules.ts` — **状态规则层**，纯函数：检疫校验、状态推导（检疫/复检事件时间线）、48 小时恢复、上笼拦截、排行/总览/提醒计算、登记/复检/更正/建训放等写操作（不可变更新）
- `src/storage/persistence.ts` + `src/storage/seed.ts` — **持久化层**：localStorage 读写（key `pigeon-trainer-db-v1`，带格式校验与回退）、演示数据
- `src/state/store.tsx` — React Context 粘合层：订阅状态、提交动作、落盘；不含判定规则
- `src/ui/*` — **界面层**：鸽棚总览、训放上笼、回棚检疫（登记/复检/更正）、成绩排行、单羽档案五个页签

状态不入库存储：鸽只的“正常/隔离/观察”完全由检疫与复检事件时间线推导，刷新后由同一份持久化数据重新计算，保持一致。
